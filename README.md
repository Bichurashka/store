Сценарии для разных ролей
---
1
- Пользователь заходит на сайт.
- Ищет товары (по имени, SKU, категории)
- Пытается добавить в корзину товары - требуется авторизация
- Логинится / Регистрируется (c подтверждением на емайл/ телефон)
- Формирует корзину
- Пополняет баланс
- Заказывает

2 
- Админ заходит в админку в 13:00
- Добавляет скидку на 14:00
- Редактирует/ Добавляет товар
- Меняет права пользователя
- Скидка применяется в 14:00
- Админу доступны СRUD по товарам, группам и скидкам

3
- Забаненный пользователь после авторизации получает всегда редирект на страницу banned.html

4
- Разработчик ?


Стек: 
---
- BE: Django
- FE: Django Templates
- Admin panel: Django admin
- API: Django REST Framework (DRF)
- Schedule: Celery + Redis
- Database: Postgres
- Linters/Formatters: Black, Flake8, isort, mypy
- Monitor: Prometheus, Graphana 
- Logging: Datadog/Kibana ?
- Exceptions: Sentry
- Всё обёрнуто в docker-compose
- poetry
